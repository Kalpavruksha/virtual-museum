# Virtual Museum (Vite + Three.js)

```bash
npm install
npm run assets     # downloads the public-domain paintings + writes CREDITS.md
npm run validate   # checks layout, exhibits, walkability
npm run dev        # open the printed URL (add ?q=low|medium|high)
```
Missing files (audio, video, GLB, your instrument photos) show a clear placeholder instead of crashing. See `public/assets/`, `AGENTS.md`, and `PROMPTS.md`.

Controls: click to enter · WASD/arrows · Shift run · mouse look · E inspect · Esc pause.
